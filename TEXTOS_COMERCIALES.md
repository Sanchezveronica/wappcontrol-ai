# Textos comerciales — WappControl AI

## Nombre provisional
WappControl AI

## Descripción corta
Organizá tus contactos, ordená oportunidades de venta y prepará seguimientos de WhatsApp desde un solo panel sencillo.

## Presentación para redes
¿Te escriben clientes y después te olvidás de hacer seguimiento?

Con WappControl AI podés empezar a ordenar tus contactos, registrar qué necesita cada persona, identificar oportunidades y preparar mensajes para continuar la conversación por WhatsApp.

Ideal para emprendedores y pequeños negocios que quieren organizar mejor sus consultas y ventas.

Estamos desarrollando la primera versión. Sumate a la lista de interesados para conocer las novedades.

## Mensaje para validar interés
Hola, estoy desarrollando una herramienta sencilla para que emprendedores puedan organizar clientes, estados de venta y seguimientos de WhatsApp. Estoy buscando personas que quieran probar el prototipo y contarme qué funciones les resultarían más útiles. ¿Te interesaría verlo cuando esté listo?

## Oferta beta honesta
Prueba inicial del prototipo de organización comercial. Incluye registro local de clientes, estados, fechas de seguimiento, plantillas y enlaces para abrir conversaciones de WhatsApp. No incluye aún cuentas multiusuario, sincronización en la nube ni envío automático. La versión de prueba no debe usarse para almacenar datos sensibles.

## No prometer todavía
- Respuestas automáticas con IA.
- Envíos automáticos o campañas masivas.
- Acceso multiusuario con datos sincronizados.
- Seguridad de nivel empresarial.
- Integración activa con API oficial de WhatsApp.
- Almacenamiento en la nube.

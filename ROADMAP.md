# Hoja de ruta — WappControl AI

## Fase 1 — Prototipo local (incluida)
- [x] Registro, edición y eliminación de contactos.
- [x] Estado comercial y fecha de seguimiento.
- [x] Búsqueda y filtros.
- [x] Plantillas y enlaces a WhatsApp.
- [x] Exportación CSV y copia/restauración JSON.
- [x] Diseño adaptable para móvil y escritorio.

## Fase 2 — Publicación estática
- [ ] Subir el archivo a GitHub Pages.
- [ ] Probar la URL en escritorio y móvil.
- [ ] Añadir una página de presentación y formulario de interés.
- [ ] Recibir comentarios de 3 a 5 negocios piloto.

## Fase 3 — MVP multiusuario
- [ ] Autenticación y recuperación de contraseña.
- [ ] Base de datos alojada y persistente.
- [ ] Modelo de datos con propietario/organización.
- [ ] Reglas de seguridad verificadas en servidor/base de datos.
- [ ] Pruebas que impidan accesos cruzados entre negocios.
- [ ] Exportar y borrar datos de cada cuenta.
- [ ] Política de privacidad y términos.

## Fase 4 — Integración de mensajería
- [ ] Revisar documentación y requisitos oficiales de WhatsApp Business Platform.
- [ ] Determinar si el flujo requiere verificación, número dedicado o proveedor.
- [ ] Estimar costos y límites antes de habilitar envíos.
- [ ] Implementar mensajes autorizados, manejo de opt-in y bajas.
- [ ] No automatizar mensajes no solicitados ni spam.

## Fase 5 — Comercialización
- [ ] Entrevistar potenciales clientes.
- [ ] Definir plan gratuito de prueba y límites transparentes.
- [ ] Publicar página de precios solo cuando las funciones existan.
- [ ] Configurar cobros y soporte.
- [ ] Monitorear costos de infraestructura y proteger datos.

## Condición para empezar a cobrar
No cobrar por funciones que no estén implementadas y probadas. El prototipo actual no es todavía un SaaS multiusuario.
